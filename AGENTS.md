# Resume Writing Guidance

Use a Google/Big Tech style for resume bullets: lead with the impact, explain the action, include the tools or methods, and quantify the result when credible.

Preferred formula:

`Accomplished X by doing Y using Z, resulting in N% / measurable impact.`

Guidelines:

- Start bullets with strong impact-oriented verbs such as improved, reduced, accelerated, enabled, built, validated, modernized, or standardized.
- Prefer measurable outcomes such as performance improvement, success rate, latency reduction, time saved, scale, reliability, adoption, or maintainability impact.
- Do not invent numbers. If no metric is available, describe the concrete engineering impact instead.
- Include relevant tools naturally in the sentence, such as Go, Gin, PostgreSQL, Kubernetes, Terraform, AWS, OpenTelemetry, Prometheus, Grafana, LLVM, or QEMU.
- Avoid vague phrasing like "worked on", "helped with", "responsible for", or "seamless" unless the impact is concrete.
- Keep bullets concise and outcome-focused.

Examples:

- Improved RISC-V Vector Extension workload performance by 2%-3% by designing and implementing custom instructions in LLVM.
- Built a RESTful data integration API using Go and Gin, enabling internal systems to exchange departmental data through a unified backend interface.
- Improved production observability across distributed microservices by instrumenting services with OpenTelemetry and standardizing trace and metric collection.
